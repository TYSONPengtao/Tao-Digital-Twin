## 过程来源

- **整理建筑重建资料**。`JIA` 项目中的各版交付说明、变更报告、核验文件与模型清单。历史压缩包的目录用来交叉核对同版交付物。
- **准备数学孪生智慧家庭模型**。`Twin_Preparation` 中的转换与导入记录、ModelSync 请求及保存结果、专题修订和验收。日常更新格式沿用该项目的《每日更新与版本规范》。

源文件列使用项目相对路径，供在原工程回查。网页公开的是过程摘要和经过整理的配图。版本记录分开标明保存通过、仅见候选或需进一步核实的情况。

## 三类编号

| 记录 | 用途 | 例子 |
| --- | --- | --- |
| 建筑模型版本 | 重建主文件和同版配套 | `V26.20` |
| UE 模型发布号 | 可编辑源与关卡构件的同步结果 | `20261030_025240_41748228` |
| 分析或交互版本 | 特定模型、开闭状态、代表风、分析外形与界面核验 | `AllOpen_20261109` |

记录日期与发布号分别保留。模型更新后，应确认旧分析数据和新几何的对应关系，再更新使用说明和证据索引。
