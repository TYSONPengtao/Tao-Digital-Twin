# 建筑重建原实现脚本

[逐版技术文章](../versions/README.md) · [建筑重建台账](../../reconstruction.md)

按 82 个已归档版本附上 **2,272 个脚本与启动文件**，覆盖建模、配准、材质、截图、导出和保存后核验。工程与历史目录中的同名同内容副本合并，原路径一并登记。

其中 **2,241 个文件保持原字节，31 个文件仅处理站点坐标并加入执行阻断**。各版 `manifest.json` 可核对源文件 SHA-256、公开文件 SHA-256、来源和脱敏原行号。原工程与历史归档均只读，未重新运行改模脚本。

这些附件用于查阅实际实现。Blender、Rhino、UE5 及 NumPy、Shapely、PyProj、Matplotlib 等依赖由原执行环境提供；未把 `plotlibs` 内的第三方库冒充项目源码打包。原有输入与输出路径予以保留，复现前须建立隔离工程并配置依赖。模型、原始实景资料与私有坐标需由本机提供。

V24.02 从 V24 工程中定位到实际入口 `v24_update_top.py`，并补入其调用的屋顶、厨房交接与 QA 模块；不是仅附截图核验脚本。V24.01 仍无独立归档，未创建虚构源码目录。
