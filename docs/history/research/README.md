- 表中 `JIA` 下的路径可在建筑重建交付中找到。以 `work/` 开头的路径来自“整理建筑重建资料”的历史工作目录。智慧家实现表使用 `Twin_Preparation` 相对路径。
- `P` 编号链接到图档页面，可用同页 CSV 查行列、原图文件和副本。单张图附原路径与发布处理。脚本的同名保存调用、同轮图、候选和保存后的结果分别说明。
